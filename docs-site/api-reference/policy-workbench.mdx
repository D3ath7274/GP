---
title: "Policy workbench read API"
description: "Loopback operator-model queries on port 8082, separate from live collection and Ryu."
---

The workbench binds http://127.0.0.1:8082 and serves a read-only browser at /. Start it using [the runbook](/deployment/policy-workbench). The source contract is docs-site/policy-openapi.json; it generates the Policy workbench endpoints navigation group. A JSON file in the Mintlify source root is not itself a published page. When the workbench runs, its lightweight reader also serves that source at http://127.0.0.1:8082/docs/policy-openapi.json.

| GET route | Input | Response |
| --- | --- | --- |
| /policy/status | None | Read-only mode, operator_description source kind, no native vendor parser, reachability NOT_EVALUATED and enforcement NOT_ATTEMPTED. |
| /policy/snapshots | Optional limit, integer 1–200, default 100 | Snapshot metadata, total and truncated flag. No offset paging in this slice. |
| /policy/snapshots/SNAPSHOT_ID | Lowercase 64-character SHA-256 ID | Normalized policy and up to 20 latest import observations with returned raw hashes checked. |
| /policy/search | snapshot, source, destination, protocol; transport ports as applicable | Candidate rule matches plus ordered header-model result, witnesses, uncertainty, count and truncation. |
| /policy/diff | before and after snapshot IDs | Same-context structural rule/object changes, changed-field values, defaults and revisions. Actor attribution is unavailable. |

Search protocols are tcp, udp, icmp and icmpv6. Source/destination must share an address family. TCP/UDP require destination_port; source_port is optional, but a constrained source port becomes unknown when omitted. Omit transport ports for ICMP. Optional limit is 1–200 and include_disabled is exactly true or false. Disabled rules may be displayed but never determine the effective header-model result. Unknown/repeated query parameters are rejected.

Model outcomes are ALLOW, DENY, REJECT or INDETERMINATE. A relevant unresolved earlier rule or global condition prevents a definite result. Display limits do not skip evaluation of later admitted rules. These are operator-model answers, not native vendor correctness, route/NAT/session analysis or live enforcement evidence.

Success returns JSON with HTTP 200. Invalid request/model/integrity input returns 400, unknown snapshot/route 404 and SQLite/store unavailability 503. POST is unsupported and the underlying HTTP handler returns 501. There is no HTTP import, apply or delete operation. CLI import is the only workbench mutation and changes only the private local database.

The prototype has no login or authenticated tenant isolation. Keep it on loopback/SSH; tenant/site labels are descriptive. Policy strings are displayed as text and query URLs are omitted from access logs. File permissions, private backups and local account boundaries remain important.
