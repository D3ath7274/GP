## Lab configuration preparation

Use Snort 3 built from its official source/build procedure at /usr/local/bin/snort; do not install Snort 2 with apt. Building/installing the binary is an operator prerequisite, not automated here. Before copying, inspect the supplied Lua HOME_NET, static ARP bindings, rule path and inspectors and adapt a private site copy. They are testbed reference settings and must not be deployed unchanged at home or a company.

```bash
/usr/local/bin/snort -V
sudo install -d /etc/snort/rules /var/log/snort
sudo install -m 644 Controller/snort3/sdn_ips_local.rules /etc/snort/rules/sdn_ips_local.rules
sudo install -m 644 /path/to/reviewed-site.lua /etc/snort/sdn_ips.lua
sudo /usr/local/bin/snort -T -c /etc/snort/sdn_ips.lua
```

Only after version/config validation, run a bounded authorized observation on an existing qualified interface:

```bash
sudo /usr/local/bin/snort -c /etc/snort/sdn_ips.lua -i MIRROR_IFACE -l /var/log/snort -A alert_json
```

Replace MIRROR_IFACE with the actual interface. This command observes alerts; it is not an inline Snort IPS or native firewall write integration. Record rule/config versions, GID/SID, packet/event time, source/destination and independent scenario truth. Inspectors can overlap and emit benign stream events. Encrypted payloads need an authorized plaintext observation point; high alert counts do not prove attacks or blocks.
