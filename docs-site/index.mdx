title: "Adaptive IPS framework"
---

Adaptive IPS framework combines behavioral traffic/device analysis with a planned multi-vendor firewall-policy management layer. Its final goal includes qualified automatic containment, policy auditing, optimization, compliance evidence, application context and verified change workflows. The [final service scope](/roadmap/final-service-scope) maps all 70 capabilities from the supplied product specification to current evidence and delivery phases.

The current Ryu deployment observes traffic crossing managed Open vSwitch and can request drop flows. The separate home collector writes site-v3.0 observations and shadow policy evidence with UNKNOWN ground truth. The nftables reference adapter is operator-run. These entry points have different detection and enforcement behavior; commercial firewall-policy collection and the enterprise services remain planned.

The legacy Ryu runtime has four detection tiers. A limited G11–G17 measurement subset is implemented in the separate home collector. Full application inspection, calibrated site-v3 models and multi-vendor policy automation require further development and qualification. Existing APF command names, paths, API routes and schema identifiers are retained for compatibility.
