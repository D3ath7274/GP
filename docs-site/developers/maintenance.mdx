Use the [data flow](/architecture/data-flow) to trace a packet or alert. Keep OpenFlow sends on the Ryu hub. Preserve the queue handoff when adding detector callbacks and preserve the single-job RF runtime setting when exporting a model. Compare feature names, order, types, defaults and model input selection before changing capture.

Use Python compilation as a syntax check. Exercise switch registration, capture and drop counters on an isolated Linux/OVS setup to verify runtime changes. Review the [verification workflow](/troubleshooting/verification) before changing mitigation.

Update the relevant page and [implementation changelog](/reference/change-log) in the same contribution. REST contract changes also require an OpenAPI update. The repository hook and PR check require an implementation changelog entry.
