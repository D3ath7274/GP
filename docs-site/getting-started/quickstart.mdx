---
title: "Choose the first qualified test"
---

Start with deterministic offline checks and policy fixtures before any firewall connection. From the repository root and the prepared Python environment:

```bash
python scripts/check_feature_catalog.py
python scripts/qualify_home_collection.py --help
python scripts/qualify_home_runtime.py --help
python scripts/policy_inventory.py --help
```

Follow [pre-test qualification](/deployment/pretest-qualification) for actual golden/restart commands and expected results. Then follow [the policy workbench](/deployment/policy-workbench) and [offline change testing](/deployment/offline-policy-changes) with the synthetic examples. These tests need no home mirror or vendor credentials and do not modify a firewall.

For actual endpoint data while visibility is unresolved, use [the no-mirror pilot](/deployment/no-mirror-pilot). For later whole-network collection use [placement](/deployment/placement), the [timed pilot](/deployment/home-pilot-step-by-step) and [home collection](/deployment/home-collection). An ordinary router LAN connection is insufficient proof of whole-home visibility.

The original [behavioral reference](/deployment/passive-sensor) remains available for legacy features/model comparisons. It is separate from the active site-v3 and policy-model tests.
