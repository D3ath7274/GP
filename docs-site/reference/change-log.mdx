## 2026-11-04 · Extended home collection and local documentation

Added a separate site-v3.0 collection entry point with bounded device summaries, IPv4/IPv6, event-time windows, daily CSVs, restored observed history, socket-loss counters and storage budgets. New G11–G14 measurements cover header behavior and long-horizon contacts. Optional limited DNS, TLS ClientHello and HTTP/1 parsers add G15–G17 evidence with explicit coverage limits. Ambient traffic remains UNKNOWN. Existing model bundles require retraining for this schema. Added a collection dashboard panel, local /docs reader, file audit, systemd template and deterministic feature tests. See [the collection guide](/deployment/home-collection).

Use a new dated heading for each implementation change. Link the affected reference pages and record the checks you ran.

## 2026-11-04 · Passive IDS sensor

Added a Ryu-independent Ethernet capture and replay entry point with a loopback dashboard, v2 CSV output and optional RF/AE observation. A firewall mirror can feed the sensor without giving APF write access. See the [passive sensor guide](/deployment/passive-sensor).

## 2026-11-04 · Reference firewall quarantine

Added an operator-run nftables adapter for scoped temporary IPv4 source quarantine, set read-back and explicit removal. See the [lab procedure](/deployment/nftables-lab).

## 2026-11-03 · Documentation baseline

Documented the four-tier runtime, operator workflows, deployment paths and management contracts. The coverage matrix maps source files to their documentation.
