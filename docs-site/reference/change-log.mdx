## 2026-11-04 · First read-only policy workbench and home visibility gates

Advanced S13–S17/S44 with an operator-description input contract, bounded address/group/port normalization, conservative ordered-header queries, transactional SQLite snapshots/raw import provenance, structural diffs and a loopback read-only UI/API. Added seven-rule IPv4/IPv6/UDP/unresolved fixtures and failure tests. This is a P7 subset; native commercial parsers, automatic polling, route/NAT simulation, usage joins and firewall writes remain planned. The [workbench runbook](/deployment/policy-workbench) provides commands and expected results, while [the code tour](/developers/policy-workbench-code-tour) explains source lines and invariant choices. The [home pilot guide](/deployment/home-pilot-step-by-step) places an actual PC/phone visibility test before a long capture on an ISP router LAN connection. No particular H188A firmware mirror capability has been established. Existing home-capture schemas, legacy model behavior and firewall enforcement paths are unchanged.

Renamed the documentation site, landing page, API display titles and current project guides to Adaptive IPS framework while preserving runtime identifiers, paths and contracts. Most enterprise services remain planned; current home collection/shadow policy and legacy lab paths are identified separately. Vendor references support service-family comparisons rather than a feature-parity claim. Existing collection and enforcement behavior is unchanged.

## 2026-11-04 · Shadow device policy and reviewed profiles

Added expiring operator-defined IP/VLAN/MAC inventory, TCP initiation role rules, explicit capture-quality states and incident holds to home collection. Separate daily evidence keeps the 71-column CSV unchanged. Candidate summaries never update approved profiles. A stopped-collector review CLI checks CSV/evidence alignment, final run quality and policy/schema provenance before writing an explicit descriptive profile. The read-only policy API and dashboard show findings and review eligibility. See [the walkthrough](/security/shadow-policy). No firewall adapter or model promotion is invoked. Existing empirical history remains unverified; calibrating decisions requires real and labeled attack data. Deterministic tests cover prohibited/allowed initiation handling, conflicts, quality faults, frozen approvals and rejected promotion inputs. Live t530/Linux qualification remains required.

## 2026-11-04 · Extended home collection and local documentation

Added a separate site-v3.0 collection entry point with bounded device summaries, IPv4/IPv6, event-time windows, daily CSVs, restored observed history, socket-loss counters and storage budgets. New G11–G14 measurements cover header behavior and long-horizon contacts. Optional limited DNS, TLS ClientHello and HTTP/1 parsers add G15–G17 evidence with explicit coverage limits. Ambient traffic remains UNKNOWN. Existing model bundles require retraining for this schema. Added a collection dashboard panel, local /docs reader, file audit, systemd template and deterministic feature tests. See [the collection guide](/deployment/home-collection).
